# Northline image asset notes

This note tracks local imagery and brand assets used by the October 2026 UI refinement. All website image references are local files under `frontend/public/assets/`; pages do not depend on external image hosts.

## Northline FM logo and favicon (13 October 2026)

- `frontend/public/assets/brand/northline-fm-mark.svg` — original geometric architectural “N” mark designed for Northline FM, using a forest-green tile, warm-ivory monogram, sage roofline, and brass baseline/accent. The shared logo component pairs this mark with the responsive “northline FM” wordmark across public pages, both homepages, the navbar, footer, authentication pages, and workspace sidebars.
- `frontend/public/favicon.svg` — matching 64 × 64 favicon derived from the same mark and palette.
- Both are original local SVGs created for this project; no third-party logo artwork is used.
